So far the site lets you pick an area and loads the road network inside it as a

--- A. WHAT THE ROUTE IS FOR -----------------------------------------------

1. What does "interval" mean for this site?
   (a) Interval training: alternating hard and easy segments, e.g. 6 x 800m fast
       with 400m recovery
   (b) Points spaced at fixed intervals along a route, e.g. a marker every mile
   (c) Something else
   Current assumption: (a)
   Answer: the interval app, which ranks people by how much territory they have surrounded (both biking and running modes)

2. What activity is it for? Running, cycling, walking, or something else?
   This decides which roads are allowed. Right now motorways and trunk roads
   are included, which is wrong for running.
   Answer: keep all roads, because over-pruning is too easy and should be done manually once a route is found

3. What route shape do you want?
   (a) A loop that ends where it started
   (b) Out and back
   (c) Point to point (start to a chosen finish)
   (d) Let the user choose
   Current assumption: (a) loop
   Answer: loop

4. If it's interval training, how should the workout be entered?
   For example: "warm-up 1 mi, then 6 x (800 m hard / 400 m easy), cool-down 1 mi".
   Should fast segments go on straight roads with few intersections or stops?
   Should the map mark where each interval starts and ends?
   Answer: once a loop is created, the starting point could theoretically be anywhere on the loop, so that should be asked to the user at the end of picking the route.

5. In Start point mode, what does "Maximum distance" mean?
   (a) How far the route may go from the start (a radius). This is what the
       code does now.
   (b) The total length of the route.
   Do you also want a separate "target route length", e.g. "about 5 miles"?
   Answer: the maximum distance they are willing to run for the loop, given a constrained point on that loop. Radius (maybe it should be half of that) is just set temporarily as an upper bound, but routes would be pruned if the closest path back to start is greater than max distance.

6. You can place several start points, but right now only the selected one
   (highlighted in blue) is used. What should multiple start points do?
   (a) Pick one; the others are just saved options (current behavior)
   (b) Make a route that passes through all of them
   (c) Make a separate route from each one
   (d) Only one start point should be allowed
   Answer: c

7. Area mode (circle or ellipse) has no start point. Where should the route
   start? Should the user also place a start inside the area, or should any
   point inside it be fine?
   Answer: there are no constraints except finding the run with the greatest isoperimetric quotient that covers at least n% of the area of that bounding shape. This is so that the user could pick say a city, and find the best route to capture the area of it and be efficient.

8. Units: miles only, or a miles/kilometers switch?
   Current assumption: miles only
   Answer: both togglable, default miles for now

12. How many route options should be shown: just the best one, or 2-3 to

    Answer: only the best route, unless specifically requested by user

- Loop solver. Start point mode: the largest-area loop through each start
  point that is no longer than its max length (roads are loaded within half
